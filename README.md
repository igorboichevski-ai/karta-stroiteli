# Карта строителей Беларуси

Веб-карта строительных компаний и компаний, работающих с неопасными отходами, с простой CRM для команды продаж. Сделана на основе [karta](https://github.com/igorboichevski-ai/karta) (карта лесной отрасли).

Типы точек: строительство зданий, сбор неопасных отходов, обработка и захоронение отходов, оптовая торговля отходами и ломом, ЖКХ, спецавтобазы, другое.

## Как устроено
- `index.html` — весь сайт (Leaflet + Supabase JS). Слои «Схема» (OpenStreetMap) и «Спутник» (Esri).
- `config.js` — адрес проекта Supabase и публичный ключ `anon`.
- `supabase/setup.sql` — схема базы и права доступа. Запускается один раз в Supabase → SQL Editor.
- Списки компаний в репозитории не хранятся: они только в базе (доступ после входа).

## Запуск
1. Создать отдельный проект Supabase и выполнить в нём `supabase/setup.sql`.
2. В Supabase → Authentication → Sign In / Providers отключить «Allow new users to sign up».
3. Сотрудников добавлять в Authentication → Users → Add user (почта + пароль, «Auto confirm»).
4. Сделать первого администратора: `update profiles set role = 'admin' where id = (select id from auth.users where email = '...');`
5. Вписать URL и ключ в `config.js`.
6. GitHub: Settings → Pages → ветка `main`. Адрес: https://igorboichevski-ai.github.io/karta-stroiteli/
7. Mapbox (по желанию): выполнить `supabase/app_settings.sql` со своим ключом.

Карта живёт на том же домене, что и карта лесной отрасли, поэтому у неё свои имена хранилищ в браузере (`ks_…`, IndexedDB `karta-stroiteli`, кеши `ks-…`): очереди и кеши двух карт не смешиваются.

## На телефоне

Сайт устанавливается как приложение (PWA): иконка на рабочем столе, карта на весь экран.
- Android (Chrome): вкладка «Список» → кнопка «Установить на телефон», или меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран Домой».

Без интернета показываются точки с последней загрузки и куски схемы OSM, которые уже открывались. Правки, комментарии, новые точки и визиты ждут в очереди и уходят, когда появится связь. Удаление работает только с интернетом.

## Источники данных
- Компании: выписки по видам деятельности (общее строительство зданий; сбор, обработка и захоронение неопасных отходов; оптовая торговля неметаллическими отходами и ломом). Статус проверен по УНП в открытом сервисе МНС (grp.nalog.gov.by), на карту попадают только действующие.
- Координаты: Nominatim, © участники OpenStreetMap, ODbL.
- Границы областей и районов (`regions.geojson`): © участники OpenStreetMap, ODbL.
